Capture Studio & CI Shot Lists

Tools → Photo Mode Pro → Capture Studio opens a dockable editor window that drives the same camera, grade stack and relight rig as the runtime photo mode — in Edit Mode, without pressing Play. Compose shots, bookmark them, and render whole batches at real publishing resolutions. No other photo-mode asset has an editor side at all; no capture asset in the category offers CI-driven shot lists.

In Play Mode with photo mode open, the studio binds to the live session: the window and the in-game UI edit the same shot.

HDRP: Play Mode only

HDRP's color grading does not apply reliably to Edit Mode camera renders (verified with the StandardRequest pipeline-render API), so on HDRP the studio (and the headless entry point) runs in Play Mode — the window says so instead of rendering wrong colors. For an exact grade preview on HDRP, open photo mode so the studio binds to the live session.

The window¶

  • Preview — a live render of the studio camera, letterboxed to the selected output preset's aspect, with an optional 5% crop-safe-area overlay.
  • Camera — grab the Scene View camera with one click, or set position, rotation and FOV numerically.
  • Grade — the core adjustment set (exposure, contrast, saturation, temperature, vignette, grain, depth of field), applied through the same pipeline backends as the runtime.
  • Light Rig — add key/fill/rim/practical/sun lights, orbit them around the focus point, tune color and intensity. Studio rig objects are session-flagged: they never dirty or save into your scene.
  • Shot List — bookmarks with apply/reorder/delete, saved into a PhotoModeShotList asset.
  • Render — render the current view to any output preset, or Render All to write the entire matrix.

Camera bookmarks¶

A bookmark stores everything a shot needs: camera pose and lens, the complete adjustment set, the focus point and the full light rig. Save View as Bookmark captures the current state; Apply restores it exactly — in Edit Mode or Play Mode.

Output presets¶

PhotoModeOutputPreset assets define exact pixel targets: dimensions, PNG or 16/32-bit EXR, supersampling, transparent background, and a watermark slot (texture, corner, offset, opacity, scale) composited at output resolution, never at preview resolution. The built-in set covers real targets:

Preset Size
Asset Store Key Image 1950×1300
Asset Store Card / Icon 420×280 / 160×160
Steam Capsules (Main / Small / Header / Library) 616×353 / 231×87 / 460×215 / 600×900
App Store Screenshot 6.5" 1284×2778
Play Store Screenshot / Feature Graphic 1080×1920 / 1024×500
Press Kit 4K 3840×2160
Wallpapers 1920×1080, 2560×1440

Create your own via Assets → Create → Photo Mode Pro → Output Preset.

Shot lists — the render matrix¶

A PhotoModeShotList asset is a matrix: bookmarks × grade presets × output presets. Leave the grade-preset list empty and each bookmark renders with its own saved look; add presets (Noir, Warm, …) and every bookmark renders once per look. File names are deterministic and collision-safe: {list}_{bookmark}_{preset}_{output}.{png|exr}.

Headless rendering (CI)¶

The same matrix renders from the command line — regenerate your entire store asset pack on every build:

Unity -batchmode -quit -projectPath . ^
  -executeMethod PhotoModePro.Editor.CaptureStudio.PhotoModeHeadlessCapture.RenderShotList ^
  -photomode-shotlist Assets/Marketing/StoreSet.asset ^
  -photomode-capture-out Renders ^
  -photomode-capture-result TestResults/shotlist_result.json ^
  -photomode-scene Assets/Scenes/Showcase.unity

The JSON result mirrors the package self-test's shape: environment fields (ProductVersion reports the installed package version) plus one record per shot with pass/fail, path, dimensions, format and wall time — ready for a CI gate:

{
  "Pass": true,
  "ProductVersion": "x.y.z",
  "Pipeline": "Urp",
  "Shots": [
    { "Name": "StoreSet_Hero_KeyImage.png", "Status": "Ok",
      "Width": 1950, "Height": 1300, "Format": "Png", "WallTimeMs": 412 }
  ]
}

-photomode-scene is optional — omit it to render whatever scene the project opens with.
