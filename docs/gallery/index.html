In-Game Gallery

The Gallery tab browses everything captured on this device: a thumbnail grid with paging, favorites, newest/oldest/favorites-first sorting, a fullscreen viewer, and per-photo capture metadata. Fully gamepad-navigable like every other tab.

  • Open full-size — click a thumbnail once to select it, again to view it fullscreen; the viewer pages with prev/next, shows an index counter and the photo's filename and capture time, and closes with CLOSE or Esc.
  • Multi-select — long-press any thumbnail for one second to enter selection mode (the held photo is ticked); click toggles further photos; Esc, CANCEL or unticking the last photo exits.
  • Favorite / Delete — favorites sort to the front in FAVS mode; deleting removes the photo, its metadata and any exported render layers that belong to it. Every delete is two-step: the first press arms the button as an inline confirmation with a visible 3.5-second countdown, the second press executes — there is no way to lose photos to a single slip.
  • Adaptive grid — thumbnails keep each photo's true aspect ratio in a three-column grid (rows size to their tallest cell, 12 photos per page), so portrait, square and ultrawide shots all read correctly.
  • Go To Shot — every capture stores its camera position, rotation and lens in a sidecar; one press re-frames the live photo camera to exactly where a saved shot was taken, ready to re-shoot with a different look.
  • Share hook — PhotoModeController.OnPhotoCaptured provides the file path for platform share integrations; the package deliberately implements no platform's share sheet itself.

Photos stay ordinary PNGs in the save folder. Metadata lives in a <photo>.png.meta.json sidecar (schema-versioned JSON); thumbnails are cached in memory behind an LRU bound, so a library of thousands of photos cannot exhaust memory.
