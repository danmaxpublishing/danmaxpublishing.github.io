LUT Filters, Looks & .cube Export

The 24 built-in filters¶

The Presets tab carries 24 LUT filters — from Teal & Orange and Bleach Bypass to Cyber Neon and Frostbite — with an intensity slider to dial each one in. They are not hand-painted textures: every filter is an adjustment recipe baked through the package's own grade pipeline into a 33³ LUT at build time, and they apply through the pipeline-independent presenter, so a filter looks the same on URP, HDRP and Built-in.

Custom LUTs¶

  • In the editor — create Assets → Create → Photo Mode Pro → LUT Filter and assign any LUT strip texture (width = size², height = size). It appears in the filter list automatically.
  • At runtime — drop .cube files or strip PNGs into the LUTs folder next to your photos and press IMPORT LUTS: industry-standard cube files from DaVinci Resolve, Premiere or anywhere else load directly.

Exporting your look as .cube¶

EXPORT .CUBE bakes the current adjustment chain — exposure, contrast, curves, tint, balance, everything color — into a 33³ LUT and writes an industry-standard .cube file to the LUTs folder. Import is table stakes; the export is the engineering half: grade a shot in photo mode, then carry that exact look into DaVinci, Premiere, OBS or another Unity project.

A round-trip test guards the fidelity: bake → write → re-parse → applying the parsed LUT reproduces the baked look exactly at every grid point.

My Looks (runtime user presets)¶

Players can save their own looks — the full adjustment set plus the relight rig — name them, reload them and delete them from the Presets tab. Looks are plain JSON files in a Looks folder beside the photos; the files are the export format. Copy a .look.json to another machine or project and it loads as-is; the LUT filter travels by name.
